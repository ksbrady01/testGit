# Central Texas Fellowship website

A one-page church homepage. The hero is an animated worship stage: a choir singing, a preacher preaching and a congregation praising. It also has a three.js sky and particle cross, and a GSAP scroll gallery of Hill Country illustrations.

| Path | What it is |
|---|---|
| `index.html` | The complete site in one file. Open it in a browser (it needs internet for Google Fonts and the cdnjs libraries). |
| `go-high-level/` | Files ready to paste into Go High Level, with a step-by-step setup guide. |
| `central-texas-fellowship-rebuild.md` | The full design and build spec, with the complete source embedded so the site can be rebuilt. |

Built with GSAP 3.12.5 + ScrollTrigger, three.js r128 and Google Fonts. There's no build step and no image files: all artwork is SVG generated in JavaScript.

Service times, links and ministry details are placeholders. See `go-high-level/README.md` for the list to replace.
