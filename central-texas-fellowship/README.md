# Central Texas Fellowship website

A cinematic one-page church site: a WebGL hero reel, "living photo" scenes (singing, preaching, praise) and scroll choreography.

- Stack: plain HTML/CSS/JS with GSAP 3.12.5 + ScrollTrigger, three.js r128 and Lenis 1.1.13, all loaded from CDNs.
- Open `index.html` through any static server (for example `python3 -m http.server`). WebGL textures won't load from `file://`.
- Photography: Unsplash (see `img/`).
- Placeholders to confirm: service times, ministry details, sermon series and quote, and town names. The visit form isn't connected to a backend yet.
